## О себе
Занимаюсь тестированием веб и мобильных приложений (iOS, Android). Работаю с функциональным, регрессионным, smoke, UI и end-to-end тестированием, тестирую API через Postman, анализирую клиент-серверное взаимодействие через DevTools. Применяю техники тест-дизайна, разрабатываю тест-кейсы и чек-листы. В портфолио — проекты по тестированию API, мобильных приложений и UI-автоматизации на Python.
